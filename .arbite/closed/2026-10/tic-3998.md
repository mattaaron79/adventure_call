## Description
The web UI exports any view as Mermaid (tic-ca91) but the CLI has no export. Add '--format mermaid' to the queries that are the CLI ports of the views -- tree (fs-tree/sunburst), imports (import graph / Local View), calls (rooted call flow) -- printing a flowchart to stdout instead of JSON, rendered from the same query results so the semantics stay identical. Same conventions as web/src/modes/mermaid.ts (header comment, n0.. ids, entity-escaped labels, hex strokes); warn on stderr past Mermaid's 500-edge / 50k-char defaults.
