## Description
Turn the raw /out JSON into the model the modes consume.

- src/data/types.ts: TS mirrors of schema_version 1 (GraphNode, GraphEdge, SymbolRecord, ModuleRecord, ImportRecord). Kinds: module|class|function|method plus the incoming variable|attribute.
- src/data/load.ts: eager fetch of codebase_graph.json (drives everything in mode 1); symbol_registry.json behind a lazy promise cache, triggered only by source viewing / external imports. Re-fetch on the out-data:changed HMR event.
- src/data/derive.ts (pure + memoized):
  * buildFsTree(moduleNodes) -> directory/file tree from file_path splits.
  * indexSymbols(nodes) -> byId, byModule, byParent (children lists).
  * deriveFileImports(edges, symbolIndex) -> deduped file->file edges from IMPORTS (module -> symbolId, map target symbol's module); keep count and the contributing symbol ids so the same edge can later re-anchor to sub-items. Drop self-edges.
- src/data/filters.ts: path-glob exclude list, default ['.pytest_tmp/**','scratch/**','**/__pycache__/**'], overridable and persisted.
- Vitest unit tests for derive.ts against a small fixture.

EXIT: sidebar reports 191 files, the directory tree, and the derived file->file import edge count.
