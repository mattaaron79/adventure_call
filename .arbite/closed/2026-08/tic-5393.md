## Description
Import lines are uniformly light gray, so selecting a node tells you nothing about what it connects to.

WORK
When an element is selected (or hovered), every import edge incident to it switches from the neutral gray to the import colour already defined in src/canvas/theme.ts, at double its normal stroke width. Nesting edges keep their current treatment; this is about import relationships specifically.

Depends on tic-1d7c, which is what gives SceneEdge its endpoint anchors -- without them there is no way to ask which edges touch the selection.

NOTES
- Incidence must follow the expand state: a collapsed file owns the import edges of every symbol inside it, so selecting the file must light all of them, while selecting one row inside an expanded container lights only that row's.
- Restyle the affected edges only. Do not rebuild the scene on selection change and do not make the edge layer listening -- selection already re-renders, so the edge layer just needs the current selection to style against.
- Draw highlighted edges above unhighlighted ones so a lit line is not buried under gray neighbours.
- Multi-selection lights the union.

EXIT: selecting a file lights its import lines in the import colour at double width and they read clearly against the unselected ones; deselecting restores them; pan/zoom framerate is unchanged.
