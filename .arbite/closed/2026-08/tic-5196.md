## Description
Add a checkbox (next to import lines / in the settings) labelled 'animate all' that, when enabled, marches the ants on every visible edge rather than only highlighted directional (import) lines. Intended as an exploratory toggle to see how continuously-animated edges look across the whole graph. Must integrate cleanly with the existing Konva.Animation: extend the registration gate so all edges opt in when the toggle is on, and reset/perf stays cheap. Answer the user's curiosity question about whether this is just CSS or expensive.
