## Description

Add a **Collapse All** button to the workspace HUD, placed just after the
existing **Relayout** button and separated from it by a small pipe `|`.

The button collapses every directory in the active fs-tree scene: all
`dir:<path>` folder expand keys are set to `false`, so directory subtrees that
are open fold up to their chips. Expanded **file** containers are left as they
are — Collapse All targets folders, not files.

### Acceptance criteria

- The HUD shows `Relayout | Collapse All` (a small vertical-bar separator
  between the two buttons, styled via `.hud-sep`).
- Clicking **Collapse All** sets every `dir:*` expand key for the active mode
  to `false`, collapsing all folder subtrees.
- Expanded file containers (and any non-`dir:` expand keys) are untouched by
  the action.
- The button is disabled when there are no directories to collapse.
- `collapseAllFolders(dirIds)` is a store action on the active mode's expand
  state and persists like any other expand change.
